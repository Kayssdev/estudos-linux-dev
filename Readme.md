# Estudos de Linux

Repositório onde documento meus estudos de Linux com alguns exemplos testados no terminal e prints!

## Sobre este repositório

- Os comandos foram testados por mim no **Fedora**. A saída pode variar em outras distros. Então é interessante verificar quais prefixos vai se adequar a sua distro.

## Conteúdo

- [Comandos de Navegação](#comandos-de-navegação): `pwd`, `ls -la`, `cd`, `mkdir`, `cp`, `mv`, `rm`, `cat`
- [Permissões e Admin](#permissões-e-admin): `sudo`, `chmod`, `chown`
- [Processos](#processos): `ps aux`, `htop`, `kill`, `systemctl status`
- [Redes](#redes): `ping`, `curl`, `wget`, `ip a`, `telnet`, `whois`, `dig`

> ⚠️ Teste comandos como `rm`, `kill` e `chown` apenas em arquivos e processos seus, nunca em arquivos do sistema.
